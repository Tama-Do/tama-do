## Tama-Do

Tama-Do is a productivity app that motivates users to complete to-do list tasks by rewarding them with items to feed virtual pet monsters at locations in the real world.

This project was developed as part of the Grace Hopper Program at Fullstack Academy's software engineering immersive program.
